# Тестовый выпуск в RuStore: альфа-тестирование

Альфа-тестирование — закрытая версия для тестировщиков по их VK ID. Её можно
выпустить первой, до публичной версии. Модерацию проходит и альфа-версия.

## Файлы

- `app-release.apk` — подписанная сборка 1.0.0 (1). Её не храним в git: собирается
  командой `gradle :app:assembleRelease`, лежит в `app/build/outputs/apk/release/`.
- `icon-512.png` — иконка 512×512, без прозрачности.
- `screenshots/` — 5 скриншотов телефона 1080×2400 на демо-данных, по порядку.

Подпись: ключ `~/Developer/ranepa-sync-android-keys/ranepa-release.jks`, пароль в
`keystore.properties`. **Сделай резервную копию обоих файлов** (например, в
менеджер паролей). Без этого ключа обновления в RuStore не выпустить: принимаются
только сборки с той же подписью.

SHA-256 сертификата: `9d:72:d2:cb:7b:9b:7f:e8:ce:22:ce:24:b5:75:46:68:36:70:f8:84:6c:23:c0:d0:35:69:f8:45:72:b8:e9:54`.

## Шаги в RuStore Консоли

1. Регистрация разработчика: console.rustore.ru → вход через VK ID → тип
   «Физическое лицо» (или самозанятый/ИП) → подтверждение личности. Проверка
   аккаунта занимает до нескольких рабочих дней.
2. «Приложения» → «Добавить приложение» → название `Расписание студента`.
3. «Тестирование» → «Альфа-тестирование» → «Загрузить» → `app-release.apk`.
4. Заполнить карточку (поля ниже), загрузить иконку и скриншоты.
5. «Тестировщики» → «Пригласить тестировщика» → VK ID через запятую (до 2000).
6. «Отправить на модерацию». После модерации появится ссылка на тестовую
   версию — её открывать **на телефоне** в приложении RuStore, на сайте будет 404.

Тестировщикам: войти в приложение RuStore под тем же VK ID, обновить RuStore до
последней версии, открыть ссылку.

**Полное описание:**

```
Расписание из личного кабинета РАНХиГС, которое открывается сразу — без браузера и без входа в ЛК каждый раз.

Открываешь приложение и видишь свой день. Пара, которая идёт сейчас, выделена, рядом написано, сколько до конца. В перерыв видно, сколько осталось до следующей.

У каждой пары есть время, аудитория и преподаватель. Если нажать на пару, откроется карточка с картой: нужный корпус подсвечен, и одним нажатием адрес открывается в Яндекс Картах, 2ГИС или Google Maps. Корпуса на Вернадского сверены со схемой кампуса, так что карта показывает именно то здание, а не общий адрес академии.

Расписание хранится на телефоне до конца семестра и открывается без интернета. Приложение само обновляет его в фоне, и если пару перенесли, отменили или поменяли аудиторию, придёт уведомление.

Что ещё умеет:
• напоминает о паре за 5, 10, 15, 30 или 60 минут;
• показывает идущую пару в строке состояния и на экране блокировки;
• виджеты «Следующая пара» и «Пары» на главном экране;
• «Предметы» и «Сессия» из плана обучения: экзамены, зачёты, консультации, преподаватели;
• добавляет пары в отдельный календарь «РАНХиГС» с адресами корпусов;
• на планшете — карточка пары рядом с лентой.

Вход — на настоящей странице личного кабинета академии. Логин и пароль приложение не видит и не хранит. Рекламы, аналитики и слежки нет, всё остаётся на телефоне. Исходный код открыт: github.com/ranepa-unofficial/ranepa-sync-android

Приложение неофициальное и не связано с РАНХиГС.
```

**Что нового** (для альфа-версии):

```
Первая версия для Android.
```

**Комментарий для модератора** (до 180 символов, здесь 174):

```
Тестовый аккаунт ЛК дать нельзя: его выдаёт только академия. Демо-режим: на стартовом экране удерживайте иконку над заголовком 1 сек. Выход из демо: аватар → «Выйти из демо».
```

## Разрешения — если модератор спросит

| Разрешение | Зачем |
|---|---|
| Уведомления | Напоминания о парах, изменения в расписании, текущая пара |
| Будильники и напоминания | Чтобы напоминание пришло точно в срок |
| Календарь | Только если включить «Добавлять в календарь» |
| Автозапуск после перезагрузки | Заново поставить напоминания |
